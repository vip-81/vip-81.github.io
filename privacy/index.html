隱私與資料

這個網站沒有帳號、沒有表單、沒有廣告，也沒有第三方分析。你的遊戲進度只存在自己的瀏覽器裡。以下是完整說明，包含我們無法控制的部分。

簡短版

不收集個人資料、不使用 cookies、不載入追蹤器。遊戲狀態存在 localStorage，鍵名前綴為 luckyforge:v1:。唯一會主動外傳資料的情況，是你按下「複製引用連結」或寄信給我們。

我們收集什麼

不收集。本站沒有註冊、登入、聯絡表單、留言、廣告或分析腳本。我們不會建立使用者輪廓，也不會把遊戲結果、裝置資訊或瀏覽行為傳送到伺服器。

網站是純靜態檔案，遊戲邏輯全部在瀏覽器執行。你不需要提供姓名、Email、電話、生日或付款資訊即可使用。

本機儲存（localStorage）

為了讓重新整理後能接續遊戲，以下資料會存在你的瀏覽器：

localStorage 鍵值與用途
鍵名內容用途
luckyforge:v1:audio-muted布林值記住音效是否靜音。

這些資料不會自動上傳，也不包含姓名、Email、IP 或裝置識別碼。它們只對同一個瀏覽器與同一個網域可見。你可以隨時清除：

  • 在遊戲頁按「補充籌碼」重設該遊戲；
  • 在瀏覽器設定中清除此網站的資料；
  • 在開發者工具 Console 執行 localStorage.clear()（會清除此網域所有鍵）。

清除後無法復原。無痕模式或企業政策可能禁止 localStorage，此時遊戲仍可玩，但重新整理後進度會消失。

Cookies 與追蹤

本站不使用 cookies，也不載入 Google Analytics、Meta Pixel、Hotjar 或任何第三方追蹤器。沒有廣告聯盟、再行銷或跨站追蹤。因此不需要 cookie 同意橫幅。

如果你透過搜尋引擎或社群連結進入本站，那些平台可能依自己的政策記錄點擊；這不在我們的控制範圍。

託管與伺服器日誌

本站部署在靜態託管平台（例如 Netlify、Cloudflare Pages、Vercel 或 GitHub Pages）。這些平台通常會為了安全、除錯與流量管理，記錄 IP 位址、User-Agent、請求路徑、時間戳與回應狀態。本站不主動讀取、分析或出售這些日誌；保存期限與處理方式取決於託管平台的政策。

若你自行下載並在本機開啟，則不會有任何伺服器請求（但請注意，直接開 file:// 可能因模組載入限制而無法執行遊戲，建議使用本機 HTTP 伺服器）。

剪貼簿

「複製引用連結」按鈕只在你點擊時呼叫 navigator.clipboard.writeText()，把目前頁面的固定網址寫入剪貼簿。我們不會讀取剪貼簿內容。若瀏覽器不支援或拒絕權限，會顯示可手動複製的網址。

來信

如果你寄信到 hello@luckyforge-lab.example，我們會收到你的 Email 位址、信件內容與你主動附上的資訊。這些資料只用於回覆與修正網站問題，不會加入行銷名單或出售。你可以隨時來信要求刪除往來紀錄。

兒童與未成年人

本站以 18 歲以上使用者為對象，不會刻意收集未成年人的資料。由於沒有帳號或表單，我們無法得知使用者年齡；若家長發現未成年人使用，請協助關閉頁面並參考責任遊戲資源。

你的權利

因為本站不持有個人資料，多數查閱、更正或刪除請求會直接指向你的瀏覽器（localStorage）或託管平台。若你曾來信，可以要求查閱、更正或刪除該信件往來。若你所在司法管轄區（例如 GDPR）提供額外權利，請來信說明，我們會合理協助。

政策變更

若未來加入表單、分析或第三方服務，我們會更新本頁並標示日期。重大變更會在首頁或相關頁面提示。最後更新：2026-11-16。

常見問題

網站會收集個人資料嗎？

不會主動收集。網站沒有帳號、表單、廣告、第三方分析或 cookies。遊戲進度只儲存在你的瀏覽器 localStorage，不會上傳。

localStorage 裡存了什麼？

只存遊戲狀態與音效偏好，例如餘額、投注、牌靴、近期結果與靜音設定，鍵名前綴為 luckyforge:v1:。不含姓名、Email 或裝置識別碼。

如何清除遊戲進度？

可在各遊戲頁按「補充籌碼」重設，或在瀏覽器開發者工具／設定中清除此網站的 localStorage。清除後無法復原。

託管平台會記錄我的 IP 嗎？

靜態託管供應商通常會基於安全與營運記錄 IP、User-Agent、請求時間與路徑。本站不讀取或分析這些日誌；實際保存期限與政策取決於你使用的託管平台。
