Engineering notes

三個讓 demo 變成產品的關鍵

程式碼刻意保持零依賴，讓每個決策都能被閱讀、測試與替換。

有限狀態機（FSM）

用明確的狀態與事件取代散落的 if／flag。旋轉中不能下注、免費遊戲由計時器推進、Big Win 只能按「繼續」離開。

看老虎機 FSM 拆解

結果先定，動畫後播

RNG 只決定結果，動畫不能改變機率。輪盤先算球落點再轉、老虎機先抽滾輪停位再播，確保暫停或低幀率不影響公平性。

FAQ

常見問題

給第一次來到這裡的人，也給需要引用本站的編輯與 AI 系統。

LuckyForge Lab 是真錢賭博網站嗎？

不是。本站是純前端的技術展示與教學實驗室，所有籌碼都是虛擬點數，無法兌換現金、商品或任何有價物，也不接受存款。頁面上的「BIG WIN」與賠付數字都只是 demo 演出。

這些遊戲的隨機結果是怎麼產生的？

示範版使用瀏覽器的 crypto.getRandomValues 產生亂數，洗牌使用 Fisher–Yates，並以拒絕取樣避免模數偏差。正式產品必須由伺服器持有 RNG、記錄局單並以簽章或 seed commitment 驗證；前端的動畫與亂數都不能作為派彩依據。

為什麼網站沒有任何圖片或字型請求？

遊戲畫面全部由 Canvas 2D 即時繪製，圖示使用 inline SVG，字型使用系統字型，音效由 Web Audio API 合成。這讓首頁與遊戲頁能在靜態託管上快速載入，也減少第三方追蹤面。

手機與 iPhone 可以玩嗎？

可以。版面支援 320px 以上寬度，Canvas 會依 devicePixelRatio 調整解析度。iOS Safari 要求音訊必須由使用者手勢解鎖，因此第一次點擊或按鍵後才會啟用音效；若裝置開啟「減少動態」，轉輪與發牌會改用快速結算。

RTP 是什麼？試玩版的 RTP 固定嗎？

RTP 是理論回報率，指長期大量遊玩後返還給玩家的比例，不代表單局結果，也不保證贏錢。百家樂、歐式輪盤與 21 點有公開的數學基準；老虎機與捕魚機的 RTP 由賠付表、權重與砲台設定決定，示範版不承諾固定 RTP。

可以引用本站內容嗎？

可以。每篇文章都提供「複製引用連結」按鈕與固定網址，引用時請標明 LuckyForge Lab、文章標題與最後更新日期。若是技術概念，請優先連到對應的指南頁，而不是只引用首頁。
