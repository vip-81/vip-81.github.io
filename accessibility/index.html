無障礙說明

遊戲可以很華麗，但操作與資訊不應該只有一種方式。這頁說明我們以 WCAG 2.2 AA 為目標做了什麼、哪些地方仍有不足，以及如何回報問題。

誠實揭露

本站尚未完成第三方無障礙稽核，因此不宣稱「完全符合 WCAG 2.2 AA」。以下列出已實作的功能與已知限制，讓使用者能判斷是否適合自己。

已實作

  • 語意結構：每頁只有一個 main、一個 h1，標題層級依序下降；導覽、麵包屑、頁尾都有可讀標籤。
  • 跳至主要內容：頁面第一個可聚焦元素是 skip link，按 Enter 可直接跳到 #main-content。
  • 鍵盤操作：所有互動元素都是原生 button 或 a；焦點樣式可見，不以 outline: none 移除。
  • 螢幕閱讀器公告：餘額、結果、錯誤與狀態透過 role="status" 或 aria-live 公告；Canvas 另外提供文字結果。
  • 減少動態：尊重 prefers-reduced-motion，跳過長時間旋轉、粒子與螢幕震動，直接顯示結果。
  • 對比與縮放：文字與背景以高對比為目標；版面在 200% 縮放與 320px 寬度下仍可操作。
  • 表單與按鈕標籤：圖示按鈕有 aria-label；籌碼與下注格有可讀名稱與目前狀態。
  • 不依賴顏色：紅／黑、輸／贏同時以文字或圖示表示，不只靠顏色。

鍵盤操作

螢幕閱讀器

頁面文字、按鈕與結果都可以被朗讀。Canvas 本身有 role="img" 與描述性 aria-label，但不提供逐格內容；遊戲的關鍵資訊（結果、餘額、點數、狀態）會同步寫入 DOM，並透過禮貌型 aria-live 公告。

若你使用 NVDA、JAWS 或 VoiceOver，建議先關閉「自動朗讀所有變更」，只保留狀態區域，避免連續公告造成干擾。若公告太頻繁，請來信告訴我們頁面與輔助科技版本。

已知限制

  • 捕魚機的瞄準：雖然提供鍵盤操作，但精準瞄準與連續開火仍以滑鼠、觸控或觸控筆較合適；這對動作障礙使用者可能造成門檻。
  • Canvas 視覺內容：輪盤、老虎機滾輪與魚群是視覺呈現，螢幕閱讀器使用者主要依賴文字結果，而不是逐格探索。
  • 動畫與閃光：Big Win 與命中特效已尊重減少動態，但部分短暫高亮仍可能造成不適；若需要完全關閉，請來信。
  • 英文與程式碼：部分程式碼與技術名詞沒有完整中文翻譯，螢幕閱讀器可能以英文發音。
  • 第三方稽核：尚未進行，因此可能有未發現的問題。

我們怎麼測試

  1. 只用鍵盤完成一局遊戲，確認焦點順序、可見焦點與 Escape 行為。
  2. 在 320px、768px、1440px 寬度與 200% 縮放下檢查版面與點擊區域。
  3. 開啟系統「減少動態」，確認動畫縮短、結果仍正確。
  4. 使用瀏覽器開發者工具的 Accessibility 樹檢查名稱、角色與狀態。
  5. 以 VoiceOver（macOS／iOS）或 NVDA（Windows）抽查主要流程。

這些測試不能取代真實使用者的回饋。若你是輔助科技使用者，歡迎告訴我們實際遇到的問題。

回報問題

請寄信到 hello@luckyforge-lab.example，並附上：

  • 頁面網址與操作步驟；
  • 瀏覽器、作業系統與輔助科技版本；
  • 你預期發生什麼、實際發生什麼；
  • 若方便，附上截圖或螢幕錄影。

我們會在確認後修正，並更新該頁的「最後更新」日期。無障礙是持續過程，不是一次性的勾選。

常見問題

網站符合 WCAG 2.2 AA 嗎？

網站以 WCAG 2.2 AA 為設計目標，但尚未完成第三方稽核，因此不宣稱完全符合。已知限制列在本頁，包括捕魚機的瞄準操作與 Canvas 視覺內容的替代資訊。

可以只用鍵盤玩嗎？

大部分可以。老虎機、百家樂、輪盤與 21 點的所有按鈕都能用 Tab 聚焦並以 Enter 或空白鍵操作；捕魚機提供方向鍵與空白鍵，但精準瞄準仍以指標裝置較合適。

如何開啟減少動態？

在作業系統設定中開啟「減少動態效果」或「Remove animations」。網站會依 prefers-reduced-motion 縮短或跳過長時間動畫，但保留結果文字與必要狀態更新。

發現無障礙問題要怎麼回報？

請寄信到 hello@luckyforge-lab.example，附上頁面網址、使用的瀏覽器與輔助科技、操作步驟與預期結果。我們會確認後修正並更新頁面的最後更新日期。
