把賭場遊戲拆開，看看裡面有什麼

LuckyForge Lab（幸運工坊）是一個純前端的 HTML5 賭場遊戲實驗室。我們做五款可以實際遊玩的虛擬籌碼試玩，也把背後的狀態機、碰撞、公平性與效能寫成可重現的工程指南。

一句話定位

不是真錢賭博網站，也不是遊戲發行商。這是一個用瀏覽器技術拆解賭場遊戲的教學專案：所有籌碼都是虛擬點數，無法兌換現金，也不接受存款。

What we do

我們做什麼

可玩的試玩

老虎機、捕魚機、百家樂、輪盤與 21 點。全部使用 Canvas 2D 與 DOM，沒有外部圖片、字型或音檔，開啟網頁就能玩。

可重現的指南

每篇指南都對應一個實際問題：滾輪怎麼停、魚群怎麼游、牌靴怎麼驗、幀率為什麼掉。附程式碼、檢查表與常見坑。

可引用的內容

固定網址、更新日期、結構化資料與「複製引用連結」。內容以繁體中文撰寫，方便讀者與 AI 摘要引用。

What we don't do

我們不做什麼

  • 不提供真錢遊戲。沒有存款、提款、兌換、紅利或任何有價物。
  • 不代替營運商。本專案不是博弈執照持有者，也不提供博弈服務。
  • 不保證任何策略。RTP 與基本策略是長期數學，不是必勝方法。
  • 不收集個人資料。沒有帳號、追蹤像素、廣告或第三方分析；詳見隱私與資料。
  • 不鼓勵未成年或問題賭博。網站標示 18+，並提供責任遊戲資源。
Editorial principles

編輯原則

技術內容必須可以被檢查，而不是聽起來很厲害。

1. 先說限制

每個 demo 都標示它是前端示範，RNG 可被修改、餘額存在 localStorage、沒有伺服器。正式產品需要什麼，會在頁面上直接寫清楚。

2. 結果先定，動畫後播

所有遊戲都先決定結果，再播放動畫。這讓低階裝置、減少動態模式與伺服器結算可以共用同一套流程。

3. 數字要有來源

RTP、賠付與機率都標明規則基準。沒有辦法精算的示範（例如老虎機權重）會直接說「不承諾固定 RTP」。

4. 無障礙是功能

鍵盤操作、焦點可見、aria-live、減少動態與對比度不是加分項，而是發佈條件。已知限制會寫在無障礙頁。

技術選型

層級選擇原因
遊戲繪製Canvas 2D不需要 WebGL 的相容性與 context lost 處理，對 2D 賭場遊戲足夠。
UI 與文字HTML／CSS可選取、可被螢幕閱讀器讀取、可用 CSS 響應式。
音效Web Audio API即時合成，無音檔請求；第一個手勢解鎖。

持久化localStorage可離線恢復；正式產品需伺服器局單與冪等結算。
託管純靜態Netlify、Cloudflare Pages、Vercel、GitHub Pages 皆可直接部署。
